Recipe block reference

  • for each i : 0 → n-1 — outer loop over position i.
  • for each j : i+1 → n-1 — inner loop over positions after i. Must sit inside an i-loop.
  • for each j : 0 → n-2 — inner loop over adjacent pairs (j and j+1).
  • repeat passes until no swaps — repeats its inside blocks until a full pass makes no swaps (an "early exit").
  • if a[ ] a[ ] — pick each side (i, i+1, j, j+1) and the operator (> / <). Runs its inside blocks only if true. One check = one stir.
  • swap a[ ] , a[ ] — exchange two values you pick. One pour.

Try:
• Selection-ish: loop i → loop j (i+1→n-1) → if a[i] > a[j] → swap a[i], a[j].
• Bubble + early exit: repeat until no swaps → loop j (0→n-2) → if a[j] > a[j+1] → swap a[j], a[j+1].
