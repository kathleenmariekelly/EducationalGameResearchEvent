Design your tower

Pick 1 or 2 abilities. A focus ability raises that stat's cap; a modifier ability adds behavior (and spends power). Then write the class below — an __init__ that sets self.damage, self.range, self.fire_rate, plus any modifier you chose. Keep total power within budget.

New to this? You already have a BasicTower — read it below and copy the pattern. In game you can run print(name) on any tower to see its stats.

class BasicTower(Tower):
    def __init__(self):
        self.damage = 8
        self.range = 160
        self.fire_rate = 2.5
